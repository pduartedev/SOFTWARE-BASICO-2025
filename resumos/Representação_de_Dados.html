Software Básico & Representação de Dados

Uma exploração interativa da arquitetura de computadores, desde o hardware físico até à execução de aplicações de alto nível.

O Sistema de Computação

Um computador é uma organização estruturada de hardware e software. O hardware executa instruções básicas, enquanto o software define o comportamento e torna o equipamento utilizável.

HW Hardware: CPU (ALU + Registradores), Memória, E/S, Barramento.
SW Software Básico: SO, Compiladores, Montadores. Conecta aplicações ao hardware.

Conceitos Chave

  • ➤ Abstração: Esconder detalhes complexos do hardware através de camadas.
  • ➤ Tradução: O caminho do código fonte C até aos bits executáveis.
  • ➤ Representação: Como números e estruturas são armazenados em bytes.

Níveis de Abstração

Laboratório de Bits: Inteiros

O computador manipula apenas 0s e 1s. Manipule os 32 bits abaixo para ver como números inteiros (Signed vs Unsigned) são representados. Note como o Complemento de 2 funciona para números negativos.

Conceitos Importantes

  • Signed (Com Sinal): Usa Complemento de 2. O Bit 31 é o bit de sinal. Se for 1, o número é negativo.
  • Unsigned (Sem Sinal): Todos os bits representam magnitude. Só armazena positivos, mas com o dobro do alcance positivo.
  • Overflow: Acontece quando uma operação resulta num valor que não cabe nos bits disponíveis.

Endianness: A Ordem dos Bytes

Arquitetura de Memória: Alinhamento de Structs

Estruturas heterogéneas (Structs) armazenam dados sequencialmente, mas para eficiência do processador, o compilador insere bytes de preenchimento (Padding) para garantir o alinhamento.

Adicionar Campos à Struct:

struct MyData {
    // Adicione campos acima...
};

Layout na Memória (Endereços relativos):

Memória Vazia. Adicione campos para visualizar o alinhamento.
Tamanho Útil: 0 Bytes
Padding (Desperdício): 0 Bytes
Total (sizeof): 0 Bytes

Regra de Alinhamento: Tipos de N bytes devem começar em endereços múltiplos de N. Por exemplo, um int (4 bytes) só pode começar nos endereços 0, 4, 8, 12... Se o endereço atual for 5, o compilador adiciona 3 bytes de padding para chegar ao 8.
